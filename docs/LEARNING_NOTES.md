# 開発学習メモ

実装中に理解した内容を、将来の記事や面接説明に使える形で追記する。

## 記録予定

- Web Audio APIでブラウンノイズを生成する仕組み
- Web Audio APIで休憩用環境音を生成し、音源ファイルを不要にする仕組み
- ブラウザのタイマーがバックグラウンドで制限される理由
- 1秒ずつ減算せず、時刻の差から残り時間を計算する理由
- PWAと通常のWebアプリの違い
- Django認証でパスワードを安全に扱う仕組み
- 独自ユーザーモデルを最初に作る理由と`AbstractUser`の継承
- CookieのセッションキーからDjangoがログイン利用者を特定する流れ
- セッション認証にCSRF対策が必要な理由
- ReactとDjango REST APIの役割分担
- PostgreSQLから日、週、月の学習時間を集計する方法
- 学習記録と振り返りを利用者ごとに分離する方法
- WebページやPWAから現在のウィンドウを確実に自動終了できない理由
