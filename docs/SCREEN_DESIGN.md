# 軽量画面設計

更新日: 2026-10-25  
状態: 初期版の画面設計確定（実装時に見た目を微調整する）

## 目的

- 初期版に必要な画面と情報の置き場所を決める。
- 見た目の細部より、操作の流れと表示漏れがないことを優先する。
- デスクトップ中心とし、画面幅を生かしつつタイマーを最も目立たせる。

## 共通部分

```text
┌────────────────────────────────────────────────────────────┐
│ 振り返り付きポモドーロ            学習記録   アカウント／ログイン │
└────────────────────────────────────────────────────────────┘
```

- アプリ名「振り返り付きポモドーロ」は左、主要な移動先とアカウント操作は右へ置く。
- タイマー画面では操作に不要な情報を増やさない。
- キーボード操作時に現在位置が分かるフォーカス表示を付ける。
- アイコンだけのボタンには`aria-label`とツールチップを付ける。

## 1. 初回の未ログイン案内

```text
┌──────────────────────────────────────┐
│ 学習時間と振り返りを保存できます       │
│                                      │
│ [ログイン]  [新規登録]                │
│ [ログインせずタイマーを使う]           │
└──────────────────────────────────────┘
```

- 初回だけタイマー画面の手前に表示する。
- ゲスト利用を選んだ後は案内を閉じ、ヘッダーに小さなログイン入口を残す。
- ログインが必須だと誤認させない。

## 2. タイマー画面

```text
┌────────────────────────────────────────────────────────────────────┐
│ 振り返り付きポモドーロ                  学習記録   アカウント／ログイン │
├────────────────────────────────────────────────────────────────────┤
│ [25分 / 5分] [52分 / 17分]                                         │
│ 25分 / 5分は4回目の学習後に15分休憩                               │
│                                                                    │
│                 ┌──────────────────────┐    今回の学習時間  1時間20分 │
│                 │   外側: 4分割進捗     │    今日の学習時間  2時間35分 │
│                 │                      │    （今回分を含む）             │
│                 │    ┌──────────┐      │                           │
│                 │    │  18:42   │      │    音量  ─────●──  [消音] │
│                 │    │ 内側:現在進捗 │      │                           │
│                 │    └──────────┘      │                           │
│                 └──────────────────────┘                           │
│                                                                    │
│                         [ ▶ / Ⅱ ]                                  │
│                       [学習を終了]                                  │
└────────────────────────────────────────────────────────────────────┘
```

- 残り時間と円形タイマーを画面の中心に置く。
- 画面の高さに収まる範囲で円形タイマーを最も大きくし、学習時間や音量操作より先に視線が向く配置にする。
- 内側の円は現在の学習または休憩の進捗を表す。
- 25分／5分設定の場合だけ、外側を4分割して長休憩までの進捗を表す。
- 52分／17分設定では外側の4分割表示を出さない。
- 円はクリックやドラッグができない外観にし、シーク操作と誤認させない。
- 再生・一時停止は同じ位置に置いた丸いボタン内で、白いアイコンを切り替える。
- 学習中の黒い画面では白い円形の枠、休憩中の薄い水色の画面では十分に濃い背景色を使い、白いアイコンが常にはっきり見えるようにする。
- 時間設定はタイマー動作中に操作不可の見た目へ切り替える。
- 今回と今日の学習時間はログイン中だけ表示する。ゲスト利用時は右側の余白を詰め、タイマーを中央に保つ。
- 今日の学習時間には、保存済みの今日の時間と現在計測中の未保存時間を合算する。「今回分を含む」と短く補足し、保存せず終了した場合は今回分を差し引く。
- 学習中と休憩中は、円の色や補助ラベルなどで判別できるようにする。ただし状態を示す長い文章は常時表示しない。

## 3. 学習終了方法

ログイン中だけ、タイマー画面上にモーダルを表示する。

```text
┌──────────────────────────────────────┐
│ 今回の学習を終了します                │
│ 今回の学習時間: 1時間20分             │
│                                      │
│ [学習時間を保存して振り返る]           │
│ [学習時間を保存して終了]               │
│ [学習時間を保存せず終了]               │
│ [タイマーへ戻る]                      │
└──────────────────────────────────────┘
```

- 「学習時間を保存せず終了」を選んだ場合だけ、別の確認モーダルを表示する。
- ゲスト利用時は終了方法を選ばず、タイマーを初期状態へ戻す。

### 終了完了表示

- 保存した場合は「学習時間を保存しました」、今回の学習時間、「学習記録を見る」「新しい学習を始める」を表示する。
- 保存しなかった場合は「今回は保存せず終了しました」と「新しい学習を始める」だけを表示する。
- 完了表示は独立画面を増やさず、タイマー画面内の状態として切り替える。

## 4. 振り返り入力・編集画面

```text
┌────────────────────────────────────────────────────────────┐
│ 振り返り                                                   │
│ 2026年10月25日 09:00–11:00   学習時間 1時間45分             │
├────────────────────────────────────────────────────────────┤
│ 今回取り組んだこと                                          │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ 複数行で入力し、入力中も全文を確認できる                 │ │
│ └────────────────────────────────────────────────────────┘ │
│                                                            │
│ 引っかかったこと                                            │
│ ┌────────────────────────────────────────────────────────┐ │
│ │                                                        │ │
│ └────────────────────────────────────────────────────────┘ │
│                                                            │
│ 引っかかったことに対して試したこと                           │
│ 試した結果、理解はどう変わりましたか？                       │
│                                                            │
│ 次に行う具体的な行動                                        │
│ ┌────────────────────────────────────────────────────────┐ │
│ │                                                        │ │
│ └────────────────────────────────────────────────────────┘ │
│                    [さらに深掘り]                           │
│                                                            │
│                                      [保存] [キャンセル]    │
└────────────────────────────────────────────────────────────┘
```

- 全項目を最初から表示し、入力条件を満たさない欄は暗くして操作不可にする。「条件未達時」などの説明文は画面へ表示しない。
- 入力欄は標準の`textarea`を使用し、macOSなどのOS標準音声入力も利用できるようにする。
- 初期版ではアプリ独自のマイクボタンと自動文字起こしを作らない。
- 「さらに深掘り」で入力欄を追加し、入力内容はすべて左揃えにする。
- 学習時間は表示のみで編集できない。

## 5. 学習記録画面

```text
┌────────────────────────────────────────────────────────────┐
│ 学習記録                                                   │
│ 今日 2時間35分   今週 12時間   今月 48時間   累計 120時間    │
├────────────────────────────────────────────────────────────┤
│ 2026年10月25日                                  合計 2時間35分│
│   09:00–11:00  1時間45分  振り返りあり                       │
│   14:00–15:00       50分  振り返りなし                       │
│                                                            │
│ 2026年10月24日                                  合計 1時間20分│
│   19:10–20:45  1時間20分  振り返りあり                       │
│                                                            │
│                       [さらに読み込む]                      │
└────────────────────────────────────────────────────────────┘
```

- 新しい日付から順に表示する。
- 日付を開くと、その日に保存した学習記録を時刻順に表示する。
- 時刻、学習時間、振り返りの有無を含む学習記録の行全体を選ぶと詳細画面へ移動する。
- 「振り返りあり」「振り返りなし」は状態表示であり、専用ボタンにはしない。振り返りがない記録も詳細画面で計測情報を確認できる。
- 最初に新しい方から20日分を読み込み、「さらに読み込む」で次の20日分を表示する。
- 初期版ではカレンダーを作らない。

## 6. 学習記録詳細画面

- 日付、開始・終了時刻、学習時間、プリセット、完了回数を表示する。
- 振り返りがある場合は全文を表示し、編集入口を付ける。
- 振り返りがない場合は「振り返りを追加」を表示し、後から同じ学習記録へ追加できるようにする。
- 深掘り項目は入力内容を左揃えにし、間の矢印だけを同じ位置までインデントする。
- 記録の削除はページ下部へ置き、確認後に学習時間・振り返り・深掘り項目をまとめて削除する。

```text
Qiitaの記事を書く
        ↓
理解できなかった用語を調べる
        ↓
調べる用語を一つ決める
```

## 7. ログイン・新規登録画面

- メールアドレスとパスワードだけを中心にした小さなフォームとする。
- 新規登録画面にはパスワード確認欄を設ける。
- エラーは該当する入力欄の近くに表示し、入力内容をすべて消さない。
- 新規登録画面には、メールアドレスと振り返り内容を保存すること、および管理者が運用上それらへアクセスできることを短く表示する。
- タイマーへ戻る入口を表示する。

## 実装時に微調整すること

- 画面サイズに応じた余白と円の大きさ
- Web Audio APIで実際に鳴らした音の聞きやすさ

## 配色方針

- 学習中は黒を基調にする。
- 休憩中は薄い水色を基調にする。
- 文字、円形進捗、操作ボタンは背景とのコントラストを確保する。
